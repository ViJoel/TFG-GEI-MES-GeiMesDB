## Caracteres para copiar y pegar directamente

### Tick / Check

✓ (Marca de verificación estándar)
✔ (Marca de verificación gruesa / negrita)
☑ (Casilla con marca)
✅ (Emoji de tick verde)

### X / Cruz

✗ (Cruz estándar)
✘ (Cruz gruesa / negrita)
☒ (Casilla con cruz)
❌ (Emoji de cruz roja)
